# Product Definition - Xinco DMS

## Vision
Xinco DMS (eXtensible INformation COre) is a powerful, web-service based Information and Document Management System (DMS). It aims to provide a robust solution for enterprises and regulated businesses to manage files, text, URLs, and contacts with high standards of security, versioning, and compliance.

## Target Audience
- **Enterprises:** Organizations requiring a scalable and secure document management system with strict version control and fine-grained Access Control Lists (ACLs).
- **Regulated Industries:** Businesses operating in environments requiring compliance with standards such as FDA 21 CFR Part 11.

## Core Value Proposition
- **Centralized Information:** A single source of truth for all critical business documents and metadata.
- **Security & Compliance:** Ensuring data integrity and auditability through ACLs, versioning, and logging.
- **Modernized Foundation:** A commitment to keeping the technology stack current, ensuring long-term maintainability and performance.

## Key Features
- **Powerful Search:** Full-text indexing and graphical search query builder supporting various formats (PDF, MS Office, HTML, etc.).
- **Advanced Access Control:** Granular ACLs for users and groups to manage information visibility and modification rights.
- **Version Control:** Check-in/check-out mechanisms that preserve full revision history and document integrity.
- **Multi-Language Support:** Native organization of multi-language data within a tree-based folder hierarchy.

## Strategic Goals
- **Codebase Modernization:** Migrating the user interface to the latest Vaadin versions and updating the backend to modern JDKs (JDK 17 or 21).
- **Quality & Stability:** Enhancing the CI/CD pipeline with comprehensive automated testing (unit and integration) and robust pipeline automation.
- **Containerization:** Improving Docker support for consistent environments across development, testing, and production.
