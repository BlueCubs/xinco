# Technology Stack - Xinco DMS

## Core Languages & Runtimes
- **Java:** The primary backend language. Currently utilizing JDK 1.8, with strategic goals to migrate to modern versions (JDK 17 or 21).

## Backend Frameworks & Libraries
- **J2EE / Jakarta EE:** Foundation for the web-service based architecture.
- **Servlet API:** For handling web requests and responses.
- **Maven:** Used for project management, dependency resolution, and build automation.

## Frontend Technologies
- **Vaadin:** Used for building the web-based user interface. Currently at version 14.7.x, with goals to modernize to the latest stable versions.

## Data Persistence
- **MySQL:** Supported as a robust and reliable database backend.
- **PostgreSQL:** Supported as a powerful alternative for data storage.

## Infrastructure & Deployment
- **Tomcat:** Preferred servlet container for deployment.
- **Jetty:** Used as a lightweight alternative, especially for development and testing.
- **Docker:** Utilized for containerization to ensure consistent environments across the lifecycle.

## Quality Assurance & Tools
- **JUnit:** Primary framework for automated unit and integration testing.
- **CI/CD Pipelines:** Integration with tools like Jenkins, Travis CI, and AppVeyor for continuous quality monitoring.
